## 五、面试可以直接讲的素材（现在就已经成立）

1. **跨语言 traceId 全链路**：Java `TraceIdFilter`（MDC + 响应头）→ HTTP 头透传 →
   Python 纯 ASGI 中间件 + loguru，实测请求头/响应头/两端日志逐条对齐。
   已用 SSE 实测反证中间件不缓冲流（90 事件 / 3.60s 跨度）。
2. **JWT refresh token 轮换的原子性**：用 Redis `DEL` 的布尔返回值抢占，
   而不是 `GET` 判断 + `DEL` 两步 —— 后者在并发下会被"双花"。
3. **防账号枚举的时序侧信道**：用户不存在时也跑一次 BCrypt，拉平响应时间。
4. **横向越权的系统性防护**：单条资源操作全部走 `requireOwnedXxx`，
   批量操作静默过滤非本人 ID，验收脚本里 9 项越权用例全部 403。
5. **任务状态与学习记录的一致性**：勾选完成写 `study_record`、取消则删除、
   重复勾选幂等 —— 保证进度统计不会重复累计或残留脏数据。
6. **两个"编译通过但真跑才炸"的缺陷**：Bean 循环依赖（用 Mapper 从设计上消除，
   而不是开 `allow-circular-references`）、Excel 导出 `NoClassDefFoundError`
   （排除 `commons-compress` 破坏了 poi-ooxml 的隐式契约）。
7. **框架静默丢字段**：LangChain 会丢弃 `reasoning_content`，原生 SDK 能拿到 ——
   接入任何 LLM 包装层都要与原生 SDK 对一遍字段。
