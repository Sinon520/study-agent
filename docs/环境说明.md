### RocketMQ 本地配置

`D:\rocketmq-all-5.5.0-bin-release\conf\broker-local.conf`（本工程新增）：

```properties
brokerClusterName = DefaultCluster
brokerName = broker-a
brokerId = 0
brokerRole = ASYNC_MASTER
flushDiskType = ASYNC_FLUSH
deleteWhen = 04
fileReservedTime = 48
namesrvAddr = 127.0.0.1:9876
brokerIP1 = 127.0.0.1
listenPort = 10911
autoCreateTopicEnable = true
autoCreateSubscriptionGroup = true
```

- `brokerIP1 = 127.0.0.1` 是必须的：不配的话 Broker 会把内网网卡地址注册到 NameServer，多网卡机器上客户端可能连不上。
- `runbroker.cmd` 已把堆内存调成 `-Xms1g -Xmx1g`、直接内存 `2g`：既够用，又不会像上游默认的 `-Xms8g` 那样在小内存机器上起不来。
- **ACL 注意**：本机这套 RocketMQ 开启了 ACL，普通 producer/consumer 会报 `check client ip or username failed`。第 1 周不写消费者；**第 4 周接入前必须先处理**（关 ACL 或给本地 IP 加白名单，详见 `docs/踩坑记录.md` 第 3 条）。

## 七、常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| `mvn` 下载依赖超时 | 未走镜像 | 检查 `~/.m2/settings.xml` 的 `<mirrorOf>*</mirrorOf>` |
| `pip install` 卡住后超时 | PyPI 直连不可用 | 加 `-i https://mirrors.aliyun.com/pypi/simple/` |
| 模型下载进度 0 | HuggingFace 直连被墙 | 设 `HF_ENDPOINT=https://hf-mirror.com` |
| 服务端口不是 8080 | 环境变量注入了 `SERVER_PORT` | `application.yml` 里已显式写 `server.port: 8080` |
| 启动报 `WeakKeyException` | `jwt.secret` 不足 32 字节 | 换更长的密钥，或设 `JWT_SECRET` |
| 发 RocketMQ 消息报 `check client ip or username failed` | Broker 开了 ACL | 见上文「ACL 注意」 |
| `javac` 报 `编码 UTF-8 的不可映射字符` | 文件被按 GBK 写过 | 见 `docs/踩坑记录.md` 第 1 条，用 UTF-8 重写并跑编码自检 |
